# OOXX 游戏规则

## 1. 棋盘

- 第一版：6×6。
- 棋盘由题目固定格和玩家格组成。
- 固定格不可修改。
- 玩家格初始为空。

## 2. 符号状态

| 状态 | 含义 | 第一版 |
| --- | --- | --- |
| `EMPTY` | 空白 | 使用 |
| `X` | 玩家填写的 X | 使用 |
| `O` | 玩家填写的 O | 使用 |
| `CLUE_X` / `CLUE_O` | 题目固定符号 | 使用，可用固定格数据表达 |
| `MARK_X` / `MARK_O` | 临时标记 | 第二阶段 |

## 3. 三条核心规则

1. 每行、每列不能出现三个及以上连续的相同符号。
2. 每行、每列的 X 和 O 数量相同。
3. 任意两行不能完全相同，任意两列也不能完全相同。

“相同”只针对已经完整填满的行或列进行判断。

## 4. 点击行为

正常模式下，玩家格点击循环：

```text
EMPTY → X → O → EMPTY
```

固定格点击无效。

## 5. 检查行为

点击“检查”后：

- 返回违反规则的格子或行列；
- UI 高亮错误位置；
- 不自动修改玩家输入；
- 棋盘未完成时不能判定成功。

## 6. 完成判定

同时满足以下条件才算完成：

- 没有空白玩家格；
- 每行和每列满足连续性规则；
- 每行和每列 X/O 数量相等；
- 行唯一、列唯一。

完成后显示成功提示，并记录完成时间。

## 7. 数据建议

题目数据至少包含：

- `puzzleId`
- `size`
- `difficulty`
- 固定格布局
- 标准答案

标准答案只用于本地校验和后续服务端校验，不能直接展示给玩家。
