# OOXX 游戏规则

## 对局规则

| 模式 | 棋盘 | 获胜条件 |
| --- | --- | --- |
| 经典 | 3×3 | 横、竖、斜连续 3 个同符号 |
| 进阶 | 5×5 | 四个方向连续 4 个同符号 |

- X 先手，双方轮流落子。
- 只能落在空格。
- 达成连线立即结束；棋盘填满且无人获胜为平局。
- 网络对战的回合、落子、胜负、认输由服务器确认。

## 算法与唯一解

- 3×3：Alpha-Beta Minimax 完整搜索，AI 选择最高分落子。
- 5×5：棋形评分，兼顾进攻、阻挡和位置优先级。
- 唯一解定义：候选落子中只有一个最高分位置。
- 网络题目必须通过格式、唯一解和服务端答案三重校验。
- 网络失败时，本地最多尝试生成候选题；仍失败则使用已验证兜底题。

## 每日挑战数据

```text
id、size、winLength、board、next、answer、title
```

`board` 使用 `X`、`O`、空值；`answer` 仅用于校验，不直接展示。

## 排行积分

- 胜利：+30
- 平局：+10
- 失败：+2

两端和服务端必须使用同一规则。
