# OOXX 项目总览

## 项目口径

本项目按课程作业和 Android 仓库统一为**井字棋/连线对战**，不再按康思网站的 6×6 逻辑填格实现。

- 鸿蒙：ArkTS + ArkUI。
- Android：仓库当前实际为 Kotlin + Jetpack Compose，并非 XML。
- 服务端：Node.js + HTTP + 原生 WebSocket。
- 视觉：以手绘 UI 图为准，竖屏优先。

## 评分功能

| 能力 | 落地方式 |
| --- | --- |
| 算法解题 | 3×3 使用 Alpha-Beta Minimax；5×5 使用棋形评分 |
| 规则理解 | 3×3 三连；5×5 四连；服务端校验落子和胜负 |
| 游戏生成 | 本地生成每日挑战候选题 |
| 唯一解 | 仅接受“唯一最高分落子”的题目，并校验服务端答案 |
| 特色 | 网络题库、排行榜、网络/蓝牙对战、游客身份 |

## 产品范围

页面与 Android 对齐：启动、引导、首页、模式选择、好友房、对局、结算、战绩/排行榜、我的。

模式：

- 经典 3×3：玩家对 AI。
- 进阶 5×5：四子连线，玩家对 AI。
- 双人同屏：本机轮流落子。
- 每日挑战：网络获取，离线生成兜底。
- 好友房：WebSocket；蓝牙作为同协议传输通道。Android 当前只有传输骨架，尚未接入真实对局。

## 核心原则

1. 游戏引擎不依赖 UI、网络和存储。
2. 网络对战由服务器维护权威状态。
3. HTTP/WS 字段、枚举、计分规则与 Android 一致。
4. 小程序身份只做游客标识，不要求用户名密码。
5. 小程序“选择游戏”版本列为加分项，主 App 完成后再做。
