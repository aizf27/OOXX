# OOXX 项目总览

## 1. 项目目标

复现康思 OOXX 逻辑填格游戏，先完成鸿蒙端单机版，再扩展鸿蒙端与安卓端的实时协作/竞速模式。

- 鸿蒙端：ArkTS + ArkUI，竖屏，移动端重新布局。
- 安卓端：Kotlin + XML。
- 服务端：预留 Node.js + 原生 WebSocket 方案，最终技术待联调前确认。
- 两端只统一数据模型和通信协议，不强行统一 UI 实现。

## 2. 当前确定范围

- 第一版只做 6×6。
- 使用固定题库，后续增加谜题生成器。
- 保留简单首页、游戏页、规则页。
- 第一版支持正常填入、检查、完成提示、计时、重启。
- 不自动提示错误；点击“检查”后返回错误格。
- 第一版预留本地保存、撤销/重做、标记模式、联网和登录入口。
- 第一版只支持单机，后续再接入跨端。

## 3. 设计原则

1. 游戏规则独立于 UI。
2. 页面只通过状态和仓库操作游戏，不直接操作存储或网络。
3. 单机使用本地仓库，联网使用远程仓库；两者接口保持一致。
4. 联网后服务器是最终状态来源，客户端只发送操作意图。
5. 协议字段、枚举和值域必须同步给安卓端。

## 4. 阶段划分

| 阶段 | 目标 |
| --- | --- |
| 一 | 鸿蒙端 6×6 单机核心 |
| 二 | 多题目、8×8/10×10、本地保存、标记、撤销/重做 |
| 三 | Node.js + WebSocket、创建/加入房间 |
| 四 | 协作解题模式 |
| 五 | 独立竞速/成绩同步模式 |
| 六 | 登录、注册、用户成绩和云端进度 |

## 5. 暂不处理

- 第一版不做自动生成题目。
- 第一版不做登录注册。
- 第一版不做 WebSocket 联调。
- 第一版不做完整官网桌面布局。
