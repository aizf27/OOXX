# OOXX 项目总览

## 技术口径

- 鸿蒙：ArkTS + ArkUI，首版竖屏。
- Android：Kotlin + Jetpack Compose。
- 服务端：计划使用 Node.js + WebSocket。
- 网络对局以服务器状态为最终结果。

## 当前能力

| 模式 | 规则 | 状态 |
| --- | --- | --- |
| 经典 3×3 | 三子连线，对战 AI | 已接入 |
| 进阶 5×5 | 四子连线，对战 AI | 已接入 |
| 双人同屏 | X、O 本机轮流落子 | 已接入 |
| 每日挑战 | 选择唯一最优落点 | 本地题已接入 |
| 好友房 | 跨端联网对战 | 仅 UI 与协议预留 |

## 当前基建

- 游戏规则、胜负判断、AI、唯一解校验与生成器。
- `GameStore` 统一管理单机对局状态。
- ArkUI 页面、主题 Token 和通用组件。
- 本地仓库、HTTP/WebSocket/蓝牙接口预留。

## 当前限制

- 战绩页仍为静态展示，仓库数据未接入 UI。
- 网络题库、排行榜、WebSocket 和蓝牙未实现。
- 2026-09-28 命令行构建因本机 DevEco SDK 组件缺失未完成验证。
