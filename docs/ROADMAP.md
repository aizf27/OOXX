# OOXX 开发路线

## P0 基建

- [x] 统一课程口径、UI 与 Android 代码基线
- [ ] 建立棋盘模型、纯算法引擎和单元测试
- [ ] 建立 Repository、Store、MatchConnection 接口
- [ ] 建立手绘风设计 Token 和页面路由骨架

## P1 单机可玩

- [ ] 启动、引导、首页、模式选择
- [ ] 3×3 对 AI、双人同屏、结算
- [ ] 5×5 四连 AI
- [ ] 战绩、本地排行榜、我的

## P2 评分重点

- [ ] 每日题目 HTTP 获取
- [ ] 网络题目唯一解校验
- [ ] 本地唯一解题目生成器
- [ ] 算法与生成器测试报告

## P3 跨端

- [ ] 对接 Node.js 服务端
- [ ] WebSocket 创建/加入房间、落子、认输、重连
- [ ] 服务器权威状态与排行
- [ ] 鸿蒙与 Android 真机联调

## P4 特色

- [ ] 鸿蒙蓝牙两机对战
- [ ] 网络多机观战/房间
- [ ] 小程序游客身份
- [ ] 小程序选择游戏加分项

## 验收底线

- 两端规则和协议一致。
- 3×3 AI 不漏必胜/必防着。
- 生成题必须能复算出唯一答案。
- 网络断开不允许客户端伪造最终结果。
