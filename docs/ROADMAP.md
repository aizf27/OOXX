# OOXX 开发路线

## 阶段一：鸿蒙端单机核心

目标：完成可玩的 6×6 版本。

- [ ] 确认项目主题色、字体和页面尺寸规范
- [ ] 建立模型、规则服务和本地仓库接口
- [ ] 准备固定 6×6 题库
- [ ] 完成首页
- [ ] 完成游戏页和棋盘组件
- [ ] 实现固定格、X/O 点击循环
- [ ] 实现规则检查和错误高亮
- [ ] 实现完成提示和计时
- [ ] 实现重启谜题
- [ ] 完成鸿蒙端基础测试

## 阶段二：单机增强

- [ ] 增加多道固定题目
- [ ] 增加难度和题目选择
- [ ] 增加 8×8、10×10
- [ ] 增加本地保存和恢复
- [ ] 增加撤销 / 重做
- [ ] 增加标记模式和清除标记
- [ ] 增加设置页面
- [ ] 增加谜题生成器设计和测试

## 阶段三：服务端基础

- [ ] 确认 Node.js + 原生 WebSocket
- [ ] 实现房间创建和加入
- [ ] 实现服务端棋盘状态
- [ ] 实现顺序处理落子
- [ ] 实现版本号和状态广播
- [ ] 实现错误码和断线恢复

## 阶段四：跨端协作

- [ ] 鸿蒙端实现远程仓库
- [ ] 安卓端按统一协议实现远程仓库
- [ ] 两端加入同一房间
- [ ] 两端共同修改棋盘
- [ ] 验证冲突、重连和完成状态

## 阶段五：独立竞速

- [ ] 增加 `COMPETITIVE` 房间模式
- [ ] 两端分别维护自己的棋盘
- [ ] 同步完成时间、错误次数和成绩
- [ ] 增加结果页

## 阶段六：账号系统

- [ ] 注册和登录
- [ ] 用户身份 token
- [ ] 用户历史成绩
- [ ] 云端进度同步

## 每阶段完成标准

- 页面流程可完整走通；
- 核心规则有测试；
- 网络阶段有断线和异常处理；
- 鸿蒙端与安卓端使用同一份协议文档；
- 关键功能完成后单独提交 Git commit。
